# 研屿

**研屿是采用 MIT 许可证的独立投研工作台。项目仓库：[lxistired/yanyu](https://github.com/lxistired/yanyu)。本包的验证范围与未验收项见下文，具体版本以对应 Git 提交为准。**

这是独立实现的有界本地研究工作台，包含本地工作区、手工计划与资料关联、文档/PDF、会议与提醒预览、录音草稿和可选本地转写。

## 项目初衷：鼓励机构自己动起来

研屿希望鼓励大型券商、互联网券商、独立研究机构等，围绕自己的研究能力与客户关系，建设自主的投研和客户服务工具。研究资源与服务经验来自长期投入；机构可以围绕自有或合法获授权的内容，把应用、流程和服务的主动权掌握在自己手中，拓展客户服务边界。

基础语音转写已经可以通过标准 API 以较低的调用成本获取，机构不必从零训练模型，也能着手建设自己的工作流。公开计费可参考[阿里云通义听悟](https://help.aliyun.com/zh/tingwu/pricing-and-billing-rules)和[腾讯云语音识别](https://cloud.tencent.com/document/product/1093/35686)。使用习惯与迁移成本不应成为停止自主建设的理由。当然，API 调用费不等于完整系统成本，工程集成、质量校验、数据安全、合规和运维仍需要持续投入。

Alpha 派早期以会议录音转写和 AI 纪要切入机构投研场景，讯兔科技的[2023 年同期介绍](https://www.rabyte.cn/detail.php?id=201)已明确描述这类功能。工具能够处理内容，不等于可以无视内容授权和传播范围。本项目坚持将合法信源、明确服务对象和客户资料保护作为使用前提。

公开争议也提醒我们重视这一边界。据[每日经济新闻报道](https://www.nbd.com.cn/articles/2026-06-03/4415995.html)，进门财经与讯兔科技的不正当竞争纠纷二审维持原判，涉及受限路演内容超出券商白名单范围传播。本项目未取得裁判全文，保留媒体归因；不将该案泛化为对 Alpha 派全部内容权属的判断，也不将其写成法院直接判决侵犯所有分析师或券商著作权。

我们借助 REA 对 Alpha 派部分客户端行为进行静态分析，并使用 Codex 独立重建相关投研工作流，探索机构自建服务能力的路径。本项目并非原版后端的完整复刻，不发布原版源码或数据；重建工具也不意味着取得第三方内容版权。

我们希望这份开源实现成为一个可动手的起点：先跑通可控的资料、会议、研究计划和引用流程，再按机构自身需求接入合法授权的数据与服务。这里的自主建设指应用与工作流的自主建设，不等于已经完成模型私有化、安全审查或生产部署。机构实际使用前，仍需完成内容授权核验、系统安全评估及功能验收。

## 快速启动（Linux）

使用 `package.json` / `.nvmrc` 指定的 Node 24.x、npm 11.x；本轮验证环境为 Node 24.22.1、npm 11.9.0。基础工作区不需要模型或 API key，PDF 功能另需 Poppler 和 util-linux 的 `prlimit`。

```sh
npm run verify:pins
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
npm test                         # 明确限定的当前核心 UI 集合，不是历史全量
npm run build
env -u JP_PRIVATE_DEMO -u JP_PRIVATE_DB_PATH -u JP_PRIVATE_DB_SHA256 \
  YANYU_DATA_DIR="$HOME/.local/share/yanyu-first-run" npm start
```

首次请把 `YANYU_DATA_DIR` 换成一个**不存在或全新、由你拥有的目录**，不要指向已有私人/生产数据库。打开控制台打印的 `READY http://127.0.0.1:端口`。仅监听本机回环地址；不应改为公网监听来绕过环境问题。`npm start` 不会自动重建前端。输入 `quit` 或 Ctrl-C 正常结束，常规数据保留。

## 已知功能边界

- 摘要明确为模拟，不是 AI 研究结论；通用自动化“成功”为内存模拟回显，不是实际研究执行或通知送达。
- PDF 查找定位提取文字，不提供原 PDF 页/坐标映射、OCR 或原生文字选区；现有批注/引用各有自己的边界。
- 提醒偏好代码存在，预览明确“未调度”；保存偏好不等于通知会送达。
- 原 32 项对应表仍缺失；已知后期 YY 编号仅用于保留历史身份，不能据此声称全部 25/32 项完成。
- 完整历史测试仍保留为 `npm run test:legacy-full`，**未通过本次完整执行**，其中部分依赖缺失的 `prepared-runtime`。不要把限定集通过改写成全量通过，也不要复制旧编译目录使其假装可复现。

本草案当前 JS 为 `dist/assets/index-CH0rOcH-.js`；首页、CSS、worklet 与源码的精确身份见 `validation/CURRENT_BUILD.json`。

本次身份清单为 `RELEASE_DRAFT_MANIFEST.json`；`verify:pins` 只校验列入文件的字节身份，不证明来源权利、功能、发布许可或真实设备可用。实际应用依赖的四份 notices 保留，构建生成 helper 的许可另保留；它们不是本项目 LICENSE。

机构私有数据入口仍在，但公开包不分发真实快照或接入配置。真实来源摘要/公司映射/日期绑定已去除，任何 JP_PRIVATE_* 配置在 provider 边界均 fail-closed；保留的五公司合成测试不表示已接通机构数据。
