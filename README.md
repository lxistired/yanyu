# 研屿｜用 REA + Codex 重建 Alpha 派

**以开源实现回应研究内容的越界传播，让大型券商、互联网券商和独立研究机构自己建设投研工具，掌握客户服务的主动权。**

研屿是一次针对 Alpha 派的开源重建实践：借助 REA 分析部分客户端功能与交互，再用 Codex 独立实现相关主要投研工作流。自有代码以 MIT 许可证开放，供机构检查、部署、修改和扩展。**我们提供工具与接入接口，不提供或托管推理服务；模型 API 与本地部署由使用机构自行选择。**

## 为什么重建 Alpha 派

研究内容流向谁、服务面向谁，应当遵守内容授权和服务约定，不能由处理内容的第三方工具擅自扩大范围。

会议转写和 AI 纪要是 Alpha 派早期的重要切口，讯兔的[2023 年官方介绍](https://www.rabyte.cn/detail.php?id=201)已展示这类能力。但工具效率不能消解授权边界。据[每日经济新闻报道](https://www.nbd.com.cn/articles/2026-06-03/4415995.html)，2026 年进门财经诉讯兔科技不正当竞争案终审维持原判：讯兔虽获券商授权录制，却将受限会议内容向白名单之外开放，被认定构成不正当竞争。这里保留媒体归因，不将该案泛化为对全部分析师或券商著作权的裁判。

这起案件涉及的越界传播，触及上游研究授权与合规服务的边界。**我们的回应，是把自主建设工具的起点开源，让内容创造者和有权机构自己动手，而不只是成为工具平台的内容供给者。**

## 我们如何回应：分析、重建、开放

研屿借助 [REA（Reverse Engineer Anything）](https://github.com/morluto/rea) 对 Alpha 派部分客户端进行静态分析，由 Codex 独立重建相关投研工作流，从工作区、资料管理、研究计划、PDF、会议与录音等流程做起。技术路线、实现代码、验证结果和未完成项都公开，供机构复核与继续建设。

感谢 morluto 与 REA 贡献者提供分析工具。研屿是独立项目，并非 REA 或 Alpha 派官方产品，也不代表上游背书；不发布原版源码或数据。

## 机构可以自己动起来

基础转写和模型能力已能通过标准 API 获取，也有可由机构本地部署的开源选项。机构不必从零训练模型，可以围绕自有或合法获授权的内容，从一个明确的研究或客户服务场景开始。API、模型、算力和数据治理由机构自主决定，我们不提供推理服务。

使用习惯和迁移成本需要面对，但不应成为放弃自主建设的理由。把工具建设与内容授权、客户需求和安全要求放在一起推进，把应用和服务的主动权掌握在自己手中。

**当前为首个公开预览版，不是原版后台的完整复刻，尚未完成生产验收及全部真实浏览器、设备和外部服务验证；具体范围见[验收说明](ACCEPTANCE.md)。**

## 快速启动（Linux）

使用 `package.json` / `.nvmrc` 指定的 Node 24.x、npm 11.x；本轮验证环境为 Node 24.22.1、npm 11.9.0。基础工作区不需要模型或 API key，PDF 功能另需 Poppler 和 util-linux 的 `prlimit`。

```sh
npm run verify:pins
npm ci --ignore-scripts --no-audit --no-fund
npm run typecheck
npm test                         # 明确限定的当前核心 UI 集合，不是历史全量
npm run build
env -u JP_PRIVATE_DEMO -u JP_PRIVATE_DB_PATH -u JP_PRIVATE_DB_SHA256 \
  YANYU_DATA_DIR="$HOME/.local/share/yanyu-first-run" npm start
```

首次请把 `YANYU_DATA_DIR` 换成一个**不存在或全新、由你拥有的目录**，不要指向已有私人/生产数据库。打开控制台打印的 `READY http://127.0.0.1:端口`。仅监听本机回环地址；不应改为公网监听来绕过环境问题。`npm start` 不会自动重建前端。输入 `quit` 或 Ctrl-C 正常结束，常规数据保留。

## 已知功能边界

- 摘要明确为模拟，不是 AI 研究结论；通用自动化“成功”为内存模拟回显，不是实际研究执行或通知送达。
- PDF 查找定位提取文字，不提供原 PDF 页/坐标映射、OCR 或原生文字选区；现有批注/引用各有自己的边界。
- 提醒偏好代码存在，预览明确“未调度”；保存偏好不等于通知会送达。
- 原 32 项对应表仍缺失；已知后期 YY 编号仅用于保留历史身份，不能据此声称全部 25/32 项完成。
- 完整历史测试仍保留为 `npm run test:legacy-full`，**未通过本次完整执行**，其中部分依赖缺失的 `prepared-runtime`。不要把限定集通过改写成全量通过，也不要复制旧编译目录使其假装可复现。

本草案当前 JS 为 `dist/assets/index-CH0rOcH-.js`；首页、CSS、worklet 与源码的精确身份见 `validation/CURRENT_BUILD.json`。

本次身份清单为 `RELEASE_DRAFT_MANIFEST.json`；`verify:pins` 只校验列入文件的字节身份，不证明来源权利、功能、发布许可或真实设备可用。实际应用依赖的四份 notices 保留，构建生成 helper 的许可另保留；它们不是本项目 LICENSE。

机构私有数据入口仍在，但公开包不分发真实快照或接入配置。真实来源摘要/公司映射/日期绑定已去除，任何 JP_PRIVATE_* 配置在 provider 边界均 fail-closed；保留的五公司合成测试不表示已接通机构数据。
